about=Calculates SCIMAP spatial indices including network connectivity, erosion risk, in-channel risk, seasonal FIO delivery risk, and flood mean/stdev outputs using native WhiteboxTools hydrological processing (BreachDepressions, FD8FlowAccumulation, D8Pointer, DInfMassFlux, Watershed, DownslopeDistanceToStream) and a flow-path trace connectivity approach. Tools: SCIMAP Sediment, SCIMAP FIO, Delineate Catchment, Apply Land Cover Risk Weights, Network Index, SCIMAP Flood, Overland Flow Distance to Point, and Export SCIMAP Results. A guided SCIMAP panel mirrors the SCIMAP web application workflow with click-on-map pour points and impact points, an editable risk weight table, and parameter set XML that is interchangeable with the web application. Land cover rasters are reclassified into SCIMAP risk weights in the plugin, so no pre-weighted raster is required. Outputs are styled automatically with percentile-stretched colour ramps and can be exported as GeoPackage, KML, point vectors, or Cloud-Optimised GeoTIFF. Depends upon the WhiteboxTools executable also being installed. https://doi.org/10.1016/j.ecolmodel.2010.08.022
